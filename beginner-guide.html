A quick boundary:

This guide intentionally does not supply prices, odds, required levels, bot returns, rebirth costs, or reward values because those details have not been independently verified.

01
Start

Get oriented

Recognize this as a simulation using in-game currency. The official description says it is not real money and is not financial advice.

02
Observe

Find a market you can describe

The game lists stocks, ETFs, futures, and IPOs. Choose one category to observe first; this is an in-site learning suggestion, not a claim about best returns.

03
Act

Place one intentional trade

A First Trade badge is officially listed. Before tapping through, decide what you are trying to learn from the trade.

04
Review

Use the portfolio and P&L calendar

Portfolio views and a P&L calendar are confirmed features. Review the outcome before adding another position.
